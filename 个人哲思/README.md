# 个人哲思

## 这里写什么

记录生活与工作中真实发生的感悟——不是摘抄，不是读书笔记的堆砌，而是"这件事让我想到了什么、印证了什么、改变了什么"。

学以致用，知行合一。所有的理论最终都要落回到自己身上：我怎么看这件事，我怎么做，做完之后我又怎么看自己。

---

## 涉及的领域

- **佛学**：无常、苦、空、因缘，以及如何在日常中真正用得上
- **道德经**：无为、水善利万物、知人者智，现代处境下的重新理解
- **哲学**：零散的思考，不拘流派，重在自己觉得有用
- **心理学**：自我觉察、关系模式、情绪与认知，用来理解自己和他人

---

## 写作方式

没有固定格式，随感而发。

可以是一段对话触发的思考，一件小事后的复盘，一段文字读到一半突然懂了的那一刻，或者某个反复出现的模式终于被自己看见。

唯一的要求：**真实**。不为说给别人听，只为自己以后翻看时，还能认出那个时刻的自己。
