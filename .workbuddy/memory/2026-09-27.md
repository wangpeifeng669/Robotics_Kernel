## 新增文章：内存带宽为何决定解码速度-算术强度与带宽三因子

- 起因：用户提问"为什么内存带宽是首帧与吐字速度的第一要素；硬件里线宽/距离/独占性为什么影响带宽"。先在对话里用 3 个可视化讲清，再沉淀成文。

- 核心论点（本文独有）：
  1. 吐字速度 = 有效带宽 ÷ 每 token 字节数（唯一瓶颈）；首帧 = 带宽当地板、算力定高度。对用户原先"带宽是首帧第一要素"的表述做了精确化限定。
  2. 算术强度是分水岭：Prefill 是 GEMM（复用 N 次），Decode 是 GEMV（复用 1 次）。同平台 7B Q8：Prefill 计算 287ms > 搬运 167ms；Decode 搬运 167ms ≫ 计算 0.14ms，相差 1190 倍。
  3. 带宽三因子 = 位宽（空间预算）× 频率（信号完整性预算）× 占用率（时间预算），相乘关系。
  4. 新补的两组量化细节（原文没有、本次推导）：
     - PCB 信号速度约 15 cm/ns → 1 cm 走线 ≈ 67 ps；DDR5-6400 一个 UI 仅 156 ps，故两线长度差超 1 cm 即吃掉大半个 UI，这就是 DDR 必须严格等长（±5 mil）的原因。
     - 线宽不能无限加大的四重约束：引脚预算、布线空间、同步开关噪声 SSN（DDR 近半引脚是电源地的原因）、全局偏斜。
