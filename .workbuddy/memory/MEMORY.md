## 文章规范要点（来自 README.md）
- 无需 frontmatter，正文直接以 H1 标题开头
- 正文开头必须有核心摘要（≤150 字），2-4 句话讲清楚结论
- 文件命名：YYYY-MM-DD_<简短主题标识>.md，中文为主，术语可用英文
- **H1 标题 = 文件名去掉日期部分**（如文件 `2026-07-08_三大国产TTS对比-MiniMax-Qwen3-豆包.md` → H1 `# 三大国产TTS对比-MiniMax-Qwen3-豆包`）
- 标题语言：正文各级标题用中文，专业术语缩写（ASR/LLM/TTS/INT4 等）除外
- 写作原则：先摘要后细节、可复现、数字说话、工程视角、精简不冗余
