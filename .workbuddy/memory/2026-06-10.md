- **来源资料**：
  - `端侧部署/2026-06-07_qwen3-tts-0.6b-deploy-benchmark.md`（本机 + 阿里云 TTS 双环境基线测试报告）
  - `C:/Users/wangp/Downloads/Gemini_2026-06-09.md`（Gemini 对话记录，含多模型共享 GPU 根因分析）
- **文章核心内容**：
  1. 多模型共用 GPU 的两大根因：SM 算力争抢（Prefill 阶段）+ 显存带宽绞杀（Decoding 阶段）
  2. 云端服务器：双卡分离（LLM 独占大卡，ASR+TTS 共用小卡），内网访问消除 RTT
  3. 局域网服务器：同上双卡方案，推荐 4090 + 4060Ti 16G 组合
  4. RK3588 端侧：NPU 物理三核绑定（Core 0 给 ASR/TTS，Core 1+2 给 LLM）
  5. S100P 端侧：hb_dnn 优先级调度 + 分句缓冲 + TROS 零拷贝通信
  6. 各场景延迟参考矩阵 + LLM 流式输出与 TTS 协同的注意点
