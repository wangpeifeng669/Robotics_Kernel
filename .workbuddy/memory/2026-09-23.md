## 讲解：Silero VAD 原理（问答，无文件产出）

用户问"silero vad 是什么原理"。已用两个内联图（前向计算链路 + 双阈值状态机）讲清，要点存档：

- **定位**：端到端流式二分类网络，约 30 万参数 / 1.2–2.25 MB，不靠手工特征。
- **前向链路**：`[1,576]`（64 上下文 + 512 新样本，@16k）→ 右侧反射填充至 640 → 可学习 STFT `Conv1d(1→258, k=256, s=128)` 出幅度谱 `[129,4]` → 4 层 Conv1d+ReLU（129→128→64→64→128，时间维 4→2→1）→ LSTM(128) → Conv1d(128→1)+Sigmoid → P(语音)。
- **三个关键认知**：① 64 样本上下文是硬契约，缺失会让干净语音概率塌到约 0.16；② STFT 是学出来的（权重里存可训练傅里叶基，无窗函数、无固定 FFT）；③ LSTM 每 32ms 只吃一帧，靠 hidden state 补足上下文。
- **可用性靠外层**：4 状态机 + 双阈值滞回（onset 0.5 / offset 0.35）+ min_speech 250ms + min_silence 100ms + speech_pad 30ms。
- **工程坑**：state 不可并发共享（每路音频一份）；前面必须状态化重采样；排序为 AEC → 降噪 → VAD。
- v5 起单文件内含 8k/16k 双分支（8k 侧 chunk 256 / context 32 / hop 64）。
