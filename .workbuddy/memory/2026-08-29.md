- 通信架构目录新增《AOQ协议解析-AI-over-QUIC》（2026-08-29_AOQ协议解析-AI-over-QUIC.md）。基于 Gemini 聊天记录（WebSocket vs WebRTC vs AOQ 选型讨论）+ 阿里云官方文档/开发者社区文章补全。
- 关键纠错：AOQ 官方全称是 **AI over QUIC**，非 Gemini 转述的 "Ali Optimized QUIC"；聊天后半段的 "AOP (Audio-over-Packet)" 是 AI 泛化说法，非真实协议，文章中已澄清。
- 核心事实沉淀：百炼 Realtime API 三协议（AOQ/WebRTC/WebSocket）；WebRTC 不支持实时 ASR/TTS 模型而 AOQ 全覆盖；AOQ 四大设计（全格式单连接承载、实时/非实时双模自适应、流级容错 60% 丢包可流畅对话、全球 Relay 就近接入）；鉴权走业务 AppServer 代理（API Key 不落端，sid 7200s）；SDK 为闭源 aar/framework/har + Linux Python，Opus 为独立插件，Android minSdk 21 支持 arm64-v8a；网关 header `x-dashscope-rtc-transport: moq` 暗示与 IETF MoQ 路线同源。
