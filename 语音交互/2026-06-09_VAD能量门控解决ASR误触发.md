机器人直接对接千问3 ASR时，其内置VAD对非人声抑制不足，电机运转声和窄波束两侧弱小声音频繁被误判为语音，导致ASR输出大量垃圾识别结果。在ASR之前增加Silero VAD概率流+动态能量门控的双重检测，仅当神经网路判定为人声且RMS能量同时满足绝对阈值与信噪比门槛时才开启ASR，基本消除了嘈杂声送入ASR的问题。

## 问题背景

机器人语音交互链路为：麦克风阵列 → 波束成形 → 千问3 ASR → 语义理解。千问3 ASR内置VAD作为语音起止判官，但在实际部署中暴露两个典型问题：

1. **电机噪声穿透**：机器人运动时，底盘电机产生的低频机械噪声被ASR的VAD误判为人声，导致ASR持续输出无意义识别结果。
2. **弱小旁瓣声穿透**：窄波束成形算法在主瓣两侧存在旁瓣泄漏，远场弱小声源（如远处人声、环境杂音）经旁瓣进入ASR后，同样被VAD误触发识别。

根本原因在于千问3 ASR自带的VAD仅依赖声学模型概率判断"像不像人声"，缺乏对声音物理能量强度的校验——低能量的远场杂音和机械噪声在频谱特征上也可能被模型判为"类人声"。

## 解决方案：VAD + 能量门控双防线

核心思路：**Silero VAD 负责"像不像人声"，能量门控负责"够不够近、够不够响"，两者同时满足才开门送ASR。**

### 第一层：Silero VAD 神经网络概率流

采用 Silero VAD（基于CNN的轻量级语音检测模型），处理16kHz单声道PCM音频：

- **组帧**：音频按512采样点（约32ms）切片送入模型，输出0~1的人声概率值。
- **双阈值迟滞机制**：
  - 开门阈值 `start_threshold = 0.8`：连续若干帧概率 ≥ 0.8 才初步认定有人说话，保证高置信度触发。
  - 关门阈值 `end_threshold = 0.45`：概率降至0.45以下才判定说话结束。
  - 双阈值设计防止吞音、语速变化导致的检测碎片化。

### 第二层：动态能量门控

神经网络对声音纹理敏感但无法区分能量大小，因此引入物理层面的二次校验。判定公式：

$$\text{avg\_rms} \ge \max(\text{min\_segment\_rms},\ \text{noise\_rms} \times 10^{\frac{\text{snr\_margin\_db}}{20}})$$

三个核心参数协同工作：

| 参数 | 配置值 | 作用 |
|---|---|---|
| `min_segment_rms` | 500 | 绝对硬门槛，低于此值直接过滤（远场弱声） |
| `snr_margin_db` | 8 dB | 动态信噪比门槛，人声必须比底噪高8dB以上 |
| 底噪估计 `noise_rms` | 滑动窗口中位数 | 100帧滑动窗口，取概率<0.2的帧做中位数估计 |

**底噪自适应**是关键设计：系统在Silero判定为非人声的帧上持续统计RMS中位数，形成动态环境底噪基准。这意味着无论环境安静还是嘈杂，能量门槛都会自动跟随调整——安静环境下底噪低、门槛低；嘈杂环境下底噪高、门槛相应提高。

### 流式场景的工程实现

机器人需要实时响应，VAD必须在说话人开口后数百毫秒内开门送ASR：

1. 持续feed音频帧，Silero实时输出概率。
2. 连续检测到满足 `min_speech_duration_ms = 300ms` 的人声后，立即计算这几帧的平均能量。
3. 能量门控通过 → `feed()` 返回 `True`，触发开门，ASR开始接收音频。
4. **句首回溯**：通过 `preroll` 缓冲区机制，在触发开门时向前回溯补发音频，防止爆破音和辅音被裁剪导致ASR首字识别不准。

### 线程安全

Silero模型在并发调用 `forward` / `reset_states` 时会导致SIGSEGV段错误崩溃，因此引入全局推理锁 `_MODEL_LOCK = threading.Lock()`，确保音频回调线程和状态重置线程互斥访问模型。

## 验证结果

方案部署后的实测效果：

- **电机噪声**：机器人全速运动时，ASR不再输出垃圾识别结果，VAD+能量门控有效拦截低频机械噪声。
- **旁瓣弱声**：窄波束两侧的远场弱小声源被绝对能量门槛（`min_segment_rms=500`）和信噪比门槛（8dB）双重过滤。
- **人声识别率**：正常距离（1~3m）面向机器人说话，开门延迟约300ms，ASR识别率未受影响。

## 调参备忘

当前参数偏向保守（抗误触发型），适合展厅、播报机器人等嘈杂场景。遇到以下情况可微调：

| 现象 | 原因 | 建议 |
|---|---|---|
| 小声或稍远说话无响应 | 绝对门槛过高 | `min_segment_rms` 500→350，或 `start_threshold` 0.8→0.65 |
| 机器人自播报尾音误触发ASR | 回声能量高 | `snr_margin_db` 8→10~12 |
| ASR首字识别不准 | 句首辅音被裁剪 | `speech_pad_ms` 0→100~150 |

## 延伸思考

这套双防线架构的本质是**用物理量校准统计模型的误判**——神经网络擅长"分类"但不擅长"度量"，能量门控恰好补上了"这个声音到底值不值得处理"的判断维度。如果未来机器人场景扩展到更安静的家庭环境，可能需要将参数切换为灵敏度模式，或引入场景自适应的参数切换机制。
