# 机器人采音链路与回采保证

**核心摘要**：采音增益的核心矛盾是麦增益与喇叭响度互相牵制——增益大则音量一大就削波，AEC 失效；增益小则远场人声掉进底噪。正确顺序是先定最大音量不削，再看 1 m 人声够不够，不够去分腔而不是拧 PGA。增益只动模拟域、四麦同步动，UI 100% 必须映射到功放离开饱和区的位置。本文以增益设计为主线展开，精简收录三轴合同、回采抽点、声学安装等前提。

---

## 1. 背景与增益问题的位置

典型机型：胸前/头部线性四麦标品模组 + 主控（RK3588 一类）跑通用阵列 SDK，TTS 走板载或外置功放。接了回采线不等于回采成立——回采要在时间（同源时钟）、通道（身份表与 `channel_num` 一致）、电平（最大音量不削波）三条轴上同时成立，其中**电平轴完全由增益设计决定**，且是产线上最常做错的一条。

让回采作废的失效模式速览：ref 抽的流与喇叭响的不是同一条；麦与 ref 时钟不同源；通道序号错位；音量打满削波；进 SDK 前被 ALSA 混音/AGC/重采样改写；喇叭麦共腔结构传声。前两条靠架构（同一 Codec/ADC、先限幅再抽回采），最后一条靠结构（分腔减振），而**削波这一条，靠的是本文的增益设计**。

> 关键认知：削波发生在模拟级或 ADC 顶满。数字域再乘 0.5，平顶还在只是变矮——已削波形不能喂 SDK，线性 AEC 拟合不了削波后的非线性。

## 2. 采音增益设计（重点）

### 2.1 核心矛盾与正确顺序

麦增益和喇叭响度是一对矛盾：增益要大（远场人声听得见）与回声不能削（音量一大麦就平顶）不可兼得时，顺序错了就全错。

**正确顺序：先定最大音量不削，再看 1 m 人声够不够；不够去分腔、换麦，而不是把 PGA 拧回去顶满。**

顺序颠倒的典型翻车：为了响度把增益顶满 → 100% 音量麦平顶 → AEC 失效 → 边播边消不干净 → 调 SDK 参数、加数字 AGC——全是在替增益还债。

### 2.2 目标电平表（增益设计的目标值）

| 路 | 最大音量目标 | 过满 | 过虚 |
|---|---|---|---|
| 4 路麦 | 峰值 −6～−10 dBFS | 平顶，AEC 失效 | 远场人声掉进底噪 |
| 回采 | 峰值 −3～−5 dBFS | 参考本身失真，越消越脏 | 对照太弱，估计不稳 |
| 喇叭在麦位声压 | ≤ 90 dB(A)，先按 85 做 | 结构传声 + 麦饱和 | 用分腔和中高频补，不推低音 |

### 2.3 增益只动模拟域，四麦一起动

把 Codec PGA、板级运放、无源衰减纳入**一张增益表**统一管理：

- **只动模拟增益**。降增益只降 PGA / 功放 / 无源衰减，不降「削波之后的数字音量」；升余量同理，禁止「ADC 之后数字缩小当余量」
- **四麦同步改**。波束和定位假设各麦一致，单独改一颗会歪。改完路间灵敏度差尽量 < 3 dB（正上方白噪声或远处人声比对峰值）
- **PGA 已最小仍削的两条正路**：加 6～12 dB 无源 pad；或换最大声压 120 dB SPL 以上的麦。没有第三条——软件救不了模拟级的顶满

### 2.4 削波曲线标定：找到电学上限，重映射 UI 100%

不凭「好像清楚一点」调，用数据定档：

1. 同一段 TTS，音量 50% / 70% / 85% / 100%（含对话音量档），记录 4 麦各自峰值 dBFS、ref 峰值、是否平顶、麦位 A 计权声压（有声级计就记）
2. 找到开始平顶的那一档——那就是当前电学上限
3. 两种改法任选其一：
   - 把 UI 100% 映射到「四麦峰值约 −6 dBFS」对应的功放增益
   - 或把功放固定增益下调 6～12 dB，让新的 100% 落在这个点

原则：**软件 100% ≠ 功放饱和**。音量曲线是电平合同的一部分，UI 满档必须落在离开饱和区的位置。

### 2.5 播放链配套：软限幅、高通、响度策略

- 播放链加**软限幅**：压峰值、保平均响度。短时爆破音打麦，平均响度仍可接受
- TTS 切掉 120～200 Hz 以下：低频最催振膜行程和壳体共振，最易结构传声和削波。听感不够响，**补中高频，不推低音**
- **对话音量与展示/警报音量分开**：对讲、唤醒、打断走对话音量（承诺全双工）；空场喊人允许短时打满，并接受该段 AEC 降级（改按键或视觉打断）——不要假装 100% 展示音量仍然全双工，写进规格

### 2.6 回采电平与增益联动标定

最大业务音量播扫频或标准 TTS：

1. ref 峰值落在 −3～−5 dBFS；不足则提高抽点增益或减小衰减，过量则加 pad
2. **同时看 4 麦：若麦已削而 ref 合格，是隔离或麦增益问题，不是把 ref 再削一刀**——两路目标不同，不能互相迁就
3. 人不说话时，SDK 回调单声道应接近静音；还能清楚听出词，就是回采未成立（抽点错、通道错、时钟漂或麦已削）

### 2.7 播放中不要现场拧 PGA

AEC 把「当前增益」当成回声路径的一部分。对话中途猛改模拟增益，等于把路径模型拦腰打断。必须在播报间切换增益档时，按序执行：**停写音频 → 改增益 → 复位引擎 → 继续写**。

### 2.8 增益设计的总闭环

增益不是孤立旋钮，它和三个外因互相成就：

- **分腔减振替增益腾空间**：结构传声让麦多吃 6～12 dB——分腔减振省下的这截，往往就是 100% 音量从削波回到合法的那一截。远场人声过虚时，先查是不是「分腔不够却把 PGA 降过头」，而不是把 100% 音量拧回去
- **时钟与抽点替增益兜底**：电平全对但时钟不同源或 ref 抽在限幅前，增益白调
- **验收集替增益留证据**：削波曲线、只播 TTS 的残回声、1 m / 3 m 唤醒、边播边打断、步行运动态——改一档增益前先有基线，改后才有对比

## 3. 其余合同要点（精简版）

### 3.1 时间轴与通道轴

- 4 麦 + ref 进同一颗 Codec / 同一 ADC，播放 DAC 与采音 ADC 锁同一主时钟；跨板必须硬件层同帧，禁止用户态「大概对齐」。麦与 ref 的固定延迟可以存在，但必须稳定——AEC 吃稳定延迟，不吃随机抖动
- 通道身份画死一张表（物理位、TDM/ALSA 号、SDK `channel_num`、资源文件版本），两个实验定序：靠近单麦说话看幅度定麦序；只播 TTS 看哪路与播报一致定 ref。资源文件按出厂麦间距编制，不改间距、不随意重排通道

### 3.2 回采抽点

```
TTS PCM → 音量曲线 → 高通(120～200Hz,可选) → 软限幅
    → ┬─ 电学回采 ─→ 与 4 麦同一 ADC ─→ SDK
      └─ DAC → 功放 → 喇叭
```

**先限幅，再抽回采**；优先 DAC 后、功放前抽。禁止：拿麦对喇叭录回采、抽限幅前的内存缓冲、双板各自晶振软件拼时间戳、换采样率/重启播放器不 Reset 引擎。双喇叭左右增益不一致时两路都采或混合后采。

### 3.3 声学安装硬指标

声孔深 < 1.5 mm、孔径 ≥ 2 mm；按住单孔该路掉 ≥ 10 dB（掉不够即腔体串音）；硅胶套减振、不与喇叭电机共骨架；喇叭口不朝麦、夹角 > 90°、间距 ≥ 100 mm；不改阵列间距。

### 3.4 软件只做搬运

进 SDK 前禁止 AGC、均衡、降噪、混立体声、二次重采样（只允许布局转换）；识别只用回调音频；唤醒后锁波束；写音频独立线程、块时长 10～20 ms 量级、不丢块；引擎没授权时回采看起来像「没效果」，其实根本没在跑。

### 3.5 三种结构选型

**A（推荐）**：播放 PCM 走 I2S 进麦阵 Codec，片内 loopback/功放前抽 ref，4 麦 + ref 同一 ADC——时钟天然同源。**B**：喇叭必须走主控功放时，限幅后 PCM 与 4 麦打进同一 TDM 帧（硬件/FPGA 嵌帧）。**C（不推荐）**：跨板数字回传，无硬件锁相不用。另两种禁用：回采空接指望盲消；展示音量直通功放饱和靠数字 AGC 补。

## 4. 故障速查

| 现象 | 先查 | 不要先做 |
|---|---|---|
| 一播 TTS 麦波形平顶 | 功放增益、音量曲线、麦 PGA、麦位声压 | 调 SDK、加数字 AGC |
| 麦不削但边播边消不干净 | ref 抽点、通道号、是否限幅后、时钟 | 换唤醒词 |
| 只播 TTS，ref 几乎没能量 | 回采线、混音是否绕开抽头 | 加大麦增益 |
| 远场人声过虚 | 分腔不够却把 PGA 降过头 | 把 100% 音量拧回去 |
| 步行一响就误唤醒 | 硅胶套、共骨架、风扇 | 再加一层进 SDK 前降噪 |
| SDK「完全没效果」 | 授权、资源文件、写线程是否送原始多通道 | 怀疑算法本身 |

## 5. 一句话收成

**增益合同：最大对话音量下麦峰 −6～−10 dBFS、ref 峰 −3～−5 dBFS，UI 100% 离开功放饱和；增益只动模拟、四麦同步，不够响去分腔，不拧 PGA。**

合同成立，回采才存在；合同一破，降噪和唤醒都在替增益还债。
