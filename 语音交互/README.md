# 语音交互

## 模块定位

本模块聚焦机器人/智能终端的**端到端语音交互链路**，从采集、理解到合成输出的全链路设计与优化。

## 核心主题

| 主题 | 说明 |
|------|------|
| 端到端演进 | 从级联式（ASR → NLU → TTS）到端到端语音模型的架构演进与选型 |
| 低延迟 ASR/TTS | 流式识别、增量合成、首包延迟（TTFT）优化策略 |
| VAD 与嘈杂环境 | 语音活动检测、噪声抑制、远场/混响场景下的鲁棒性处理 |

## 典型问题

- 如何在 200ms 内完成「说完 → 开始播放」的交互闭环？
- 工厂/展厅等高噪环境下 VAD 误触发如何抑制？
- 流式 ASR 与 LLM 推理如何流水线并行？

## 目录建议

```
语音交互/
├── architecture/     # 链路架构图、时序设计
├── asr/              # 语音识别方案与 benchmark
├── tts/              # 语音合成与音色管理
├── vad/              # VAD、降噪、AEC 相关
└── benchmarks/       # 延迟/准确率测试记录
```

## 关联模块

- `通信架构/` — 语音流与控制指令的传输通道
- `模型原理/` — 端到端语音大模型原理
- `端侧部署/` — 端侧 ASR/TTS 部署与算力约束
