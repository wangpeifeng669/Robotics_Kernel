# 前沿分析

## 模块定位

本模块关注 AI 与机器人领域的前沿趋势与范式变革，聚焦行业级技术演进、工程范式转移及对开发者实践的影响。不是新闻搬运，而是"这个趋势意味着什么、对现有工作方式有什么冲击、我们该怎么应对"的判断与思考。

## 写作原则

1. **有判断才写**：不做资讯罗列，必须有明确的观点和推理链条。
2. **有数据支撑**：趋势判断尽量引用可验证的行业数据或案例，避免纯主观推测。
3. **关联自身实践**：优先分析与自身工作（端侧部署、语音交互等）有关联的前沿动向，写出"跟我有什么关系"。
4. **时效性标注**：前沿分析有时效性，文章中注明信息截止时间。
