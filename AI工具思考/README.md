# AI 工具思考

## 模块定位

本模块记录 AI 工具使用过程中的真实思考与实践总结，聚焦 Cursor 等 AI 辅助开发工具的使用技巧、workflow 设计与效能提升。不是工具说明书的摘抄，而是"用下来有什么体会、踩了什么坑、哪些做法真正提升了效率"的实践沉淀。

## 写作原则

1. **有体会才写**：不对工具功能做全面介绍，只写实际使用中有感受、有结论的部分。
2. **有细节才写**：能具体到配置片段、提示词示例、操作步骤的，不放空话。
3. **有对比才写**：用了多个工具或有不同做法的，写出差异和取舍理由。
4. **数字说话**：效能提升有可描述的变化就写，避免"大幅提升"等模糊表述。
