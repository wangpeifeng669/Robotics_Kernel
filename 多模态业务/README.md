# Business Multimodal · 业务多模态

## 模块定位

本模块面向**机器人业务场景的多模态交互**，涵盖肢体动作与语音/内容的时序对齐，以及直播、导购等业务逻辑设计。

## 核心主题

| 主题 | 说明 |
|------|------|
| 肢体动作对齐 | 动作库、时间轴、与 TTS/字幕的 lip-sync 或 gesture-sync |
| 机器人直播 | 推流、互动话术、礼物/弹幕与动作触发 |
| 业务交互逻辑 | 状态机、场景切换、异常降级与人工接管 |

## 典型问题

- 一句话对应多个预设动作，如何选择与插值过渡？
- 直播卡顿或 ASR 延迟时，动作队列如何缓冲与丢弃？
- 展厅导览 vs 直播间话术，如何共用底层能力、隔离业务配置？

## 目录建议

```
Business_Multimodal/
├── motion/           # 动作库、时间轴、对齐算法
├── live/             # 直播架构、OBS/RTMP、互动协议
├── state_machine/    # 业务状态机与场景配置
├── configs/          # 各业务线 YAML/JSON 配置模板
└── demos/            # 端到端 Demo 与录屏说明
```

## 关联模块

- `Voice_Interaction` — 语音驱动动作与回复时序
- `Comm_Architecture` — 直播推流与控制信令
- `Data_Engineering` — 业务知识库与 RAG 话术
